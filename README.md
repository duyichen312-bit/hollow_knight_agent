# Hollow Knight Vision AI Agent (空洞骑士纯视觉智能体)

基于纯视觉输入（DirectX 极速截屏 + 实时目标追踪 + Gemini 多模态战略大脑 + 毫秒级战术微操反射）构建的《空洞骑士》自主游玩智能体。

## 🌟 核心特性
- **实时赛博朋克 AI 战术 HUD**：动态渲染敌我目标锁定框、跳跃/下劈弹道抛物线轨迹、血量与灵魂能量仪、实时 FPS 及大模型思维气泡。
- **双环控制架构**：
  - **毫秒级反射环 (60 FPS)**：实时自动判定小怪对战距离、空中精准下劈（Pogo Jump）、危险冲刺闪避与安全聚集回血。
  - **多模态战略环 (Gemini 2.5/Flash)**：异步解析全景战局、推荐探索路径与 Boss 战攻略。
- **纯视觉输入**：无需修改游戏内部数据，完全基于屏幕画面感知与虚拟手柄/按键指令注入。

## 🚀 快速启动
1. 启动 Steam 并运行《空洞骑士》。
2. 游戏设置：**选项 -> 视频 -> 全屏模式设置为 无边框（Borderless）**。
3. 配置 API Key（可选，在 .env 中填写 GEMINI_API_KEY=xxx）。
4. 运行智能体：
   `ash
   python main.py
   `
5. 快捷键：
   - 在 HUD 窗口中按 q 或 ESC：退出智能体。
   - 按 p：暂停 / 恢复 AI 自主控制（随时无缝切回人工操作）。
